# wawona
Wawona Cloud — 全球风控与身份验证 API 服务

**接口服务如下：**

### WhatsApp 检测
- **Whatsapp Detection**

### 印度证件 OCR
- **India Pan Card OCR**
- **India Aadhaar front OCR**
- **India Aadhaar back OCR**

### 印度电话号码真实性验证
- **Jio Phone Number Detection**
- **Airtel Phone Number Detection**
- **VI Phone Number Detection**
- **India BSNL Phone Number Detection**
- **India Jio_VI_Airtel_BSNL Phone Number Detection**

### 印度证件真实性检测
- **India Aadhaar And Pan Link Detection**（Aadhaar 和 Pan 卡是否关联）
- **India Pan Detection**（Pan 卡号是否真实存在）
- **India Aadhaar Detection**（Aadhaar 卡号是否真实存在）

### 哥伦比亚 ID OCR
- **Colombia ID front OCR**
- **Colombia ID back OCR**

### 印尼 KTP OCR
- **Indonesia KTP (ID) OCR**

### 墨西哥 ID OCR
- **Mexico ID (INE) OCR**

### 人脸活体检测（H5 版本）
- **Face-Liveness-Detection (H5)**
